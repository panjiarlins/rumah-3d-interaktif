# Rumah Sumsel – 3D interaktif

Model 3D interaktif rencana renovasi rumah (Three.js). Buka halaman GitHub Pages repo ini di browser.

- Seret untuk memutar, gulir untuk zoom, klik kanan untuk menggeser.
- 18 sudut pandang siap pakai, mode jalan (WASD), tampilan tanpa atap, Tahap A/C, dan posisi matahari per jam.
- Ukuran dari denah (cm). Warna dan material adalah usulan.
